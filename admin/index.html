Criar um produto novo

Do zero até o teste passando, pronto para entrar no catálogo.

Ver prompt
Crie um produto ORIGINAL para a loja (pasta loja/ deste projeto). Não copie nada de biblioteca/ nem de modelos/ (são de terceiros).

Produto: [nome] — [o que é, em 2 ou 3 frases]
Categoria: [dashboards, formularios, cards, botoes, navegacao, ecommerce, animacoes, loaders, icones, landing, componentes] · Preço: [valor em reais, 0 = grátis]
Direção visual: [ex.: escuro grafite com verde-água / claro editorial creme]

Passos:
1. Rode: cd loja && npm run novo -- "[nome]" --categoria [categoria] --preco [preço]
2. Construa em produtos/<slug>/demo/ com HTML, CSS e JS puros, sem dependências (só Google Fonts), tokens no :root, classes prefixadas, prefers-reduced-motion e acessibilidade (foco visível, aria, contraste AA).
3. A primeira tela em 1440×900 vira a capa: deixe-a cheia e bonita, com as animações de entrada terminando em até 1,5 s.
4. Escreva o LEIAME.md (como usar, trocar cores, onde ficam os dados) e preencha o produto.json (resumo até 140 caracteres, descrição, destaques, inclui, tags, previa).
5. Rode npm run testar -- <slug> e corrija tudo; confira com screenshot em 1440 e 390px.
6. Mude "publicado" para true e me mostre o resultado.

Recriar inspirado num modelo antigo

Usa só a IDEIA de um modelo da biblioteca e cria um original, seguro para vender.

Ver prompt
Quero um produto ORIGINAL para a loja inspirado só no CONCEITO do modelo "[nome da pasta em biblioteca/]".

Regras: não copie código, textos, ilustrações nem a identidade visual dele. Pegue apenas a ideia da interação (ex.: "campo de código que gira como cofre") e crie um design, nomes, cores e código seus, melhores e mais completos.

Depois siga o fluxo de produto novo da loja: npm run novo, demo em HTML/CSS/JS puros, LEIAME.md, produto.json, npm run testar -- <slug> passando e capa bonita em 1440×900.
Categoria: [categoria] · Preço: [preço]

Lançar nova versão de um produto

Melhora um produto existente e atualiza quem já comprou.

Ver prompt
Melhore o produto loja/produtos/[slug]/:
- [o que melhorar: ex.: tema claro, mais um gráfico, correção no celular]

Depois:
1. Suba a versão no produto.json (1.0.0 → 1.1.0 para novidades, 1.0.1 para correções) e registre as mudanças no LEIAME.md (seção "Novidades").
2. Rode npm run testar -- [slug] e corrija tudo.
3. Rode npm run publicar -- --seco e me mostre o que será enviado (eu confirmo antes do envio real).

Escrever os textos de venda

Resumo, descrição e destaques mais vendedores (e honestos).

Ver prompt
Leia o código de loja/produtos/[slug]/demo/ e reescreva no produto.json:
- "resumo" (até 140 caracteres): o que é e para quem
- "descricao" (300 a 500 caracteres): o problema que resolve, o que vem no pacote e por que economiza tempo
- "destaques" (4 a 6 itens curtos): só o que o código realmente faz
- "tags" (5 a 8)
Tom: direto, em português do Brasil, sem exageros e sem prometer o que não existe. Rode npm run testar -- [slug] no final.

Auditar o catálogo inteiro

Roda os testes, revisa capas e aponta o que melhorar.

Ver prompt
Faça uma auditoria da loja (pasta loja/):
1. Rode npm run testar e npm run testar:site e corrija qualquer falha.
2. Veja as capas (produtos/*/capa.jpg): aponte as que estão vazias, escuras demais ou sem destaque, e melhore a primeira tela desses produtos.
3. Revise os produto.json: resumos acima de 140 caracteres, destaques genéricos, preços fora do padrão do catálogo.
4. Sugira 5 produtos novos que faltam no catálogo, com nome, categoria e preço.
Me entregue um resumo do que foi corrigido e das sugestões.
